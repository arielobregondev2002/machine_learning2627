# Logistic Regression (02_logistic_regression)

This folder contains a basic implementation of logistic regression for binary classification. The code demonstrates how to compute the sigmoid activation, the cross-entropy loss, and how to update weights using gradient-based optimization. The example is intended to teach the fundamentals of probabilistic binary classifiers and decision boundaries.

Key files

- `simple_logistic_regression.py` — A self-contained example that trains a logistic regression model on a toy dataset and shows predictions and accuracy.

How to run

Run the example with:

```bash
python 02_logistic_regression/simple_logistic_regression.py
```

The script trains on a small dataset, prints training loss over iterations, and reports basic evaluation metrics. Use it to experiment with regularization, learning rates, or dataset separation.
