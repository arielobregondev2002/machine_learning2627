# machine_learning2627

This repository contains concise, educational Python implementations of classic machine learning algorithms, organized as a series of focused examples. Each numbered folder contains a self-contained example demonstrating a specific algorithm and simple scripts to train and evaluate small models. The code is intended for learning and experimentation rather than production use.

Contents

- 01_linear_regression — Simple and multiple linear regression examples and a basic gradient descent implementation.
- 02_logistic_regression — A straightforward implementation of logistic regression for binary classification with an example training script.
- 03_decision_tree_classifier — A basic decision tree classifier demonstrating tree construction and prediction.

How to use

Run the example scripts from each folder (for example: `python 01_linear_regression/simple_linear_regression.py`) to see a toy dataset training flow. Inspect the individual folder READMEs for file-level details and usage instructions.
