# machine_learning2627

This repository contains simple, educational Python implementations of classic machine learning algorithms. It is organized into numbered folders (each representing a focused topic) with standalone example scripts demonstrating how the algorithm works and how to train a simple model. The code is intended for learning and experimentation rather than production use.

Contents

- 01_linear_regression — Implementations and examples for linear regression (simple and multiple) and a basic gradient descent optimizer.
- 02_logistic_regression — A straightforward implementation of logistic regression for binary classification with an example training script.
- 03_decision_tree_classifier — A basic decision tree classifier implementation showing tree construction and prediction.

How to use

Each folder contains Python scripts that can be run directly (for example: `python simple_linear_regression.py`). Scripts use small, included or synthetic datasets to demonstrate training and evaluation. Review the individual folder READMEs for details about files and usage patterns.
