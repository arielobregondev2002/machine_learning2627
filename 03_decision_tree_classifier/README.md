# Decision Tree Classifier (03_decision_tree_classifier)

This directory implements a simple decision tree classifier to demonstrate tree construction, splitting criteria, and prediction logic. The implementation focuses on the core ideas of recursive partitioning and how feature thresholds produce leaf predictions, suitable for educational purposes.

Key files

- `decision_tree_classifier.py` — Implementation of a basic decision tree classifier with functions for building the tree and making predictions.

How to run

Run the classifier example or import the module to experiment:

```bash
python 03_decision_tree_classifier/decision_tree_classifier.py
```

The code uses small sample data to build a tree and demonstrate how predictions are made. It is useful for studying how different split criteria or maximum depth affect model behavior.
