# Linear Regression (01_linear_regression)

This folder provides simple, educational implementations of linear regression algorithms. It demonstrates both simple linear regression (single feature) and multiple linear regression (multiple features), plus a basic gradient descent optimizer to fit model parameters. The examples are small and designed to illustrate core concepts such as hypothesis, cost function, and iterative optimization.

Key files

- `simple_linear_regression.py` — Example script that fits a line to a small dataset and shows predictions and evaluation.
- `multiple_linear_regression.py` — Example illustrating linear regression with multiple input features.
- `gradient_descend.py` — A basic gradient descent implementation used by the examples to minimize the cost function.

How to run

Execute example scripts directly, for example:

```bash
python 01_linear_regression/simple_linear_regression.py
```

Each script uses a small or synthetic dataset and prints training progress and simple evaluation metrics. Use these scripts to study how model parameters change with training and to experiment with learning rates and iterations.
